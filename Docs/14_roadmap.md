# Product Roadmap

## Phase 1 - Kwara MVP

### Public

- Official website
- About
- Registration
- Registration status
- Verified directory
- News
- Events/gallery
- Contact

### Core

- Multi-step registration
- Document upload
- Admin dashboard
- Verification workflow
- Certificate generation
- Letter of Recognition generation
- Secure document retrieval
- Search/filter
- XLSX/CSV/PDF export
- Audit log
- Role-based access

## Phase 2 - Operations

- Forum self-service portal
- Announcements
- Notification system
- Activity reporting
- Better analytics
- Bulk member import
- Training/event registration

## Phase 3 - Nationwide

- All states
- State administrators
- LGA/ward structures
- National dashboard
- State comparison reports
- Nationwide verified directory

## Phase 4 - Advanced

Only after governance and privacy controls are mature:

- Member-level registration
- Digital membership IDs
- QR verification
- Advanced communication segmentation
- Field activity reporting
- Volunteer coordination

Do not build every Phase 4 feature into the MVP. The first job is to create a trustworthy registry and reliable verification workflow.
