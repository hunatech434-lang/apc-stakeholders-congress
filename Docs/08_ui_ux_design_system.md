# UI / UX & Design System

## Design direction

The website should feel like an official civic/political organization platform, not a campaign flyer.

Priorities:

1. Trust
2. Clarity
3. Mobile usability
4. Fast registration
5. Strong information hierarchy
6. Accessibility

## Homepage structure

1. Header
2. Hero
3. Trust/mission statement
4. What we do
5. Registration CTA
6. Coverage / geographic structure
7. Verified groups preview
8. Latest updates
9. Events/gallery
10. Get involved
11. Contact
12. Footer

## Registration UX

Use a multi-step form rather than one giant wall of fields.

Suggested steps:

- Forum
- Location
- Contacts
- Structure
- Track Record
- Commitment
- Support
- Documents
- Review & Submit

Show progress.

Autosave drafts where feasible.

Never wipe the entire form because one field fails validation.

## Mobile-first

Primary users are expected to use phones and WhatsApp.

Requirements:

- Large touch targets
- Minimal typing
- Native select/date controls where appropriate
- Image compression before upload
- Clear validation messages
- Sticky progress/action area where useful
- Fast loading on Nigerian mobile networks

## Accessibility

Target WCAG 2.2 AA where practical.

- Keyboard navigation
- Visible focus states
- Adequate contrast
- Proper labels
- Error association
- Alt text
- Semantic HTML
- Screen-reader-friendly status messages

## Design system

Create reusable tokens for:

- Typography
- Spacing
- Radius
- Shadows
- Borders
- Buttons
- Inputs
- Selects
- Cards
- Badges
- Alerts
- Tables
- Modals
- Navigation

Avoid overusing green. Political identity can be represented through restrained brand usage while maintaining a professional interface.
