# Content & CMS Specification

## Content types

### Announcement

- Title
- Summary
- Body
- Audience
- Publish date
- Expiry date
- Attachment
- Author
- Status

### News

- Title
- Slug
- Excerpt
- Body
- Featured image
- Category
- Author
- Publish date
- Status

### Event

- Title
- Description
- Date/time
- Venue
- LGA
- Registration/contact information
- Image
- Status

### Gallery

- Album
- Title
- Caption
- Media
- Date
- Location
- Status

## Audience targeting

Prepare for future targeting by:

- State
- LGA
- Ward
- Forum category
- Verified groups
- Admin roles

Do not implement mass messaging until the organization has approved its communication consent and opt-out policies.

## Editorial workflow

Draft -> Review -> Published -> Archived

Content changes should retain author and timestamp metadata.
